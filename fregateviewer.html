Parseur de fichiers à format XML

Charge un fichier XML de configuration, puis un fichier plat à parser : en-tête, lignes métier techniques, pied, puis message fonctionnel Z-MSG.

Glisser-déposer ici le XML de configuration et le fichier à parser
Formats acceptés : .xml, fichier plat, .gz/.gzip
En attente des fichiers.
Hypothèses de parsing 
1. La première ligne du fichier est parsée avec FILE ID="EN_TETE".
2. La dernière ligne du fichier est parsée avec FILE ID="EN_PIED".
3. Les lignes intermédiaires sont parsées avec le FILE ID donné par C-FMTMSG dans l'en-tête : EDD, GE, AO, PFG ou RELI.
4. Pour chaque ligne métier, C-APPL + SC-APPL permettent de trouver TYPE dans APPLICATION_CODE / SUB_CODE.
5. Le champ Z-MSG est ensuite parsé avec FILE ID="TYPE" si ce format existe dans le XML.
6. Cas FREGATE + EDD : parsing intermédiaire via FILE ID="FREGATE_EDD", puis agrégation des lignes ayant le même N-SEQ dans l’ordre de N-ENREG avant parsing fonctionnel.
7. Si le fichier métier sélectionné est en .gz/.gzip, il est décompressé en mémoire avant parsing.
